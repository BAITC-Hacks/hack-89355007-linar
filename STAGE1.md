# Этап 1. Цифровая модель компании

В `lib/organization.js` находится учебная вымышленная компания. Модель содержит семь подразделений, их руководителей и должности, подчинённость через `parentId`, функции, полномочия, ответственность и ссылки на процессы через `processIds`. Процессы имеют собственные стабильные ID.

Запустите `npm.cmd ci` и `npm.cmd start` в Windows PowerShell, затем откройте раздел «Модель компании». Данные доступны для следующих этапов по `GET /api/organization`. Для проверки структуры выполните `npm.cmd test`.

Это демонстрационные сведения: имена сотрудников, персональные данные и реальные документы Казахтелекома здесь не используются. Модель пока только читается; сценарии изменения структуры и нормативная проверка относятся к следующим этапам.
