# Нормативная база учебной организации

`catalog.json` хранит источники и отличает внешние ссылки от синтетических документов. `requirements.json` содержит отдельные контрольные требования: `sourceId → clause → statement → criterion`. Внешние источники приведены как справочные ссылки; их полные тексты не включены, контрольные требования из них не выводятся автоматически и соответствие законодательству не оценивается. Для применения в реальной организации эксперт должен проверить редакцию, точные пункты и утвердить извлечённые требования.

Учебные требования REQ-001–REQ-004 созданы из синтетических внутренних правил и сценария. Проверка требований: `GET /api/requirements`; каталог: `GET /api/regulatory`. Результат `GET /api/requirements/check?period=after` показывает только наличие ожидаемой функции/владельца в учебных документах и не является юридическим заключением.
