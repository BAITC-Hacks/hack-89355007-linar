# Этап 2. Синтетические сотрудники

`lib/employees.js` содержит 15 вымышленных сотрудников. Для каждого заданы ФИО, должность, ID подразделения из этапа 1, образование, стаж, сертификаты, компетенции, полномочия, функции и ответственность. Пустой список сертификатов означает, что в демонстрационной записи они не указаны.

В интерфейсе откройте «Сотрудники». Данные также доступны по `GET /api/employees`. Проверка `validateEmployees` контролирует уникальность ID, принадлежность должности подразделению и наличие одного руководителя в каждом подразделении. Демо не содержит реальных персональных данных; записи доступны только для чтения.

На Windows: `npm.cmd test`, затем `npm.cmd start`. Этот этап не переносится в `main` до решения пользователя.
